# Smart Closet API Control Hub

**Python · FastAPI · SQLite · Raspberry Pi · ESP32/WLED**

Backend for a weather-aware smart closet: preference persistence, clothing recommendations, and optional Wi-Fi LED control through WLED.

## Why this project
This repository is a portfolio-grade reconstruction/cleanup of work completed during Sandeep Dahal's Computer Science studies and personal projects. It emphasizes readable structure, reproducible setup, and practical engineering documentation.

## Highlights
- Clean, focused implementation with minimal dependencies
- Reproducible local setup
- Source separated from tests/examples where applicable
- Suitable as a foundation for continued development

## Getting started
See the source tree and language-specific dependency/build files in this repository. Clone the repository, install the listed dependencies (if any), and run the included example or test target.
